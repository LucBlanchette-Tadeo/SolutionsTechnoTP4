étape 1. OUVRIR L'APPLICATION DOCKER DESKTOP

étape 2. SUR UNE FENETRE POWERSHELL (ASSUREZ VOUS DE METTRE LE DOSSIER poc-svelte-spring-postgres SUR LE DESKTOP) :

cd .\Desktop\poc-svelte-spring-postgres\db
docker compose up -d

étape 3. SUR LA MÊME FENÊTRE POWERSHELL :
cd ..\backend
./mvnw clean spring-boot:run

ASSUREZ-VOUS DE GARDER LA FENÊTRE POWERSHELL OUVERTE, C'EST LE BACKEND

étape 5. À LA RACINE DU PROJET SUR LE DESKTOP, RIGHT-CLIC, OUVRIR AVEC CODE

étape 6. OUVRIR TERMINAL DE CODE :
cd .\frontend
npm install
echo VITE_API_URL=http://localhost:8080/api > .env
npm run dev -- --host
