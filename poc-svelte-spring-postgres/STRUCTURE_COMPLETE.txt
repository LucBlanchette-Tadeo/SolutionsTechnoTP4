⚙️ FLUX DE DONNÉES - Enregistrer un résultat
══════════════════════════════════════════════════════════════════════════════

1. FRONTEND (Utilisateur)
   ├─ Sélectionne : Course + Bateau + Temps brut + Formule
   └─ Clique : "Enregistrer"
      │
      ▼
2. API Client (api.ts)
   ├─ submitRaceResult(classeCourseId, bateauId, tempsBrutSecondes, typeHandicap)
   └─ POST http://localhost:8080/api/race-results/submit
      │ Body : { classeCourseId, bateauId, tempsBrutSecondes, typeHandicap }
      │
      ▼
3. Controller (RaceResultController)
   ├─ @PostMapping("/submit")
   └─ raceResultService.submitRaceResult(...)
      │
      ▼
4. Service (RaceResultService)
   ├─ Récupère Bateau + ClasseCourse
   ├─ Récupère py ou tmf selon typeHandicap
   └─ Appelle HandicapCalculator
      │
      ▼
5. Calculator (HandicapCalculator)
   ├─ Si PY : (tempsBrut × 1000) / py
   ├─ Si TMF : tempsBrut × tmf
   └─ Retourne tempsCorrige
      │
      ▼
6. Service sauvegarde
   ├─ raceResultRepository.save(result)
   └─ Retourne RaceResult complété
      │
      ▼
7. Controller retourne
   ├─ RaceResultDTO avec :
   │  ├─ id, bateauName
   │  ├─ tempsBrut, tempsBrutFormatted
   │  ├─ tempsCorrige, tempsCorrigenFormatted
   │  └─ typeHandicap, statut
   │
      ▼
8. Frontend affiche
   ├─ Message succès
   ├─ Recharge le tableau
   └─ Tableau mis à jour avec classement


📊 FLUX CLASSEMENT - Afficher les résultats
══════════════════════════════════════════════════════════════════════════════

1. Utilisateur sélectionne une course
   │
   ▼
2. Frontend appelle GET /api/race-results/course/{courseId}
   │
   ▼
3. Backend :
   ├─ Récupère tous les résultats de la course
   ├─ Les trie par tempsCorrige (croissant)
   ├─ Appelle HandicapCalculator.rankResults(results)
   │  └─ Assigne positionCorrigee = 1, 2, 3, ...
   └─ Retourne List<RaceResultWithRank>
      │
      ▼
4. Frontend reçoit les résultats classés
   │
   ▼
5. Affiche dans le tableau :
   ├─ Position (1🥇, 2🥈, 3🥉)
   ├─ Bateau
   ├─ Temps brut
   ├─ Handicap (PY ou TMF)
   └─ Temps CORRIGÉ en orange ⭐


🧮 EXEMPLE COMPLET - Deux bateaux course
══════════════════════════════════════════════════════════════════════════════

DONNÉES DE TEST :
  Laser : PY = 1050.00
  J70   : PY = 1000.00

ENREGISTREMENT 1 : Laser #101
  ├─ Temps brut : 3600 secondes
  ├─ Handicap : PY
  ├─ Calcul : (3600 × 1000) / 1050 = 3428.57 sec
  ├─ Formaté : 00:57:08
  └─ Sauvegardé

ENREGISTREMENT 2 : J70 #201
  ├─ Temps brut : 3500 secondes
  ├─ Handicap : PY
  ├─ Calcul : (3500 × 1000) / 1000 = 3500.00 sec
  ├─ Formaté : 00:58:20
  └─ Sauvegardé

CLASSEMENT FINAL :
  Position | Bateau   | T.Brut   | Handicap | T.Corrigé
  ---------|----------|----------|----------|----------
     1️⃣     | Laser101 | 01:00:00 |   PY     | 00:57:08 ⭐
     2️⃣     | J70 201  | 00:58:20 |   PY     | 00:58:20 ⭐

RÉSULTAT :
  ✅ Le Laser gagne MALGRÉ un temps brut plus long !
  ✅ Cela rend la course équitable entre les classes

🎯 CAS D'USAGE SUPPORTÉS
══════════════════════════════════════════════════════════════════════════════

1. ✅ Course monotype avec handicap PY
   → Tous les bateaux sont de la même classe mais avec coefficients différents

2. ✅ Course monotype avec handicap TMF
   → Alternative plus simple que PY

3. ✅ Mélanger PY et TMF dans la même course
   → Bateau A en PY, Bateau B en TMF → classement unique

4. ✅ Plusieurs courses successives
   → Créer plusieurs "courses" et enregistrer les résultats séparément

5. ✅ Modifier un résultat
   → Supprimer l'ancien, enregistrer le nouveau
