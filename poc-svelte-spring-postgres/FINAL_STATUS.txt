🧮 FORMULES IMPLÉMENTÉES
═════════════════════════════════════════════════════════════════════════════

FORMULE PY (Portsmouth Yardstick)
  Temps Corrigé = (Temps Brut × 1000) / PY
  
  Exemple :
    Temps brut : 3600 secondes (01:00:00)
    PY Laser : 1050
    Résultat : (3600 × 1000) / 1050 = 3428.57 sec (00:57:08)
    
  Code :
    public static BigDecimal calculatePY(BigDecimal tempsBrutSecondes, BigDecimal py) {
        BigDecimal numerator = tempsBrutSecondes.multiply(new BigDecimal("1000"));
        return numerator.divide(py, 2, RoundingMode.HALF_UP);
    }

FORMULE TMF (Time Multiplying Factor)
  Temps Corrigé = Temps Brut × TMF
  
  Exemple :
    Temps brut : 3600 secondes
    TMF Laser : 0.98
    Résultat : 3600 × 0.98 = 3528.00 sec (00:58:48)
    
  Code :
    public static BigDecimal calculateTMF(BigDecimal tempsBrutSecondes, BigDecimal tmf) {
        return tempsBrutSecondes.multiply(tmf).setScale(2, RoundingMode.HALF_UP);
    }


📡 ENDPOINTS API
═════════════════════════════════════════════════════════════════════════════

POST /api/race-results/submit
  Enregistrer un résultat brut
  Body : { classeCourseId, bateauId, tempsBrutSecondes, typeHandicap }
  Response : RaceResultDTO avec temps corrigé

GET /api/race-results/course/{classeCourseId}
  Récupérer les résultats classés d'une course
  Response : List de résultats triés par temps corrigé

GET /api/race-results/{id}
  Récupérer un résultat spécifique
  Response : RaceResultDTO

DELETE /api/race-results/{id}
  Supprimer un résultat
  Response : { message: "Résultat supprimé" }

❓ QUESTIONS FRÉQUENTES
═════════════════════════════════════════════════════════════════════════════

Q : Pourquoi mon bateau a un temps PLUS court ?
A : Parce qu'il est classé comme rapide ! Les handicaps rendent la course équitable.

Q : Quelle formule choisir ?
A : PY pour compétitions officielles, TMF pour courses amicales.

Q : Où voir les coefficients ?
A : Dans HANDICAP_CONFIG.md, ou en requête SQL SELECT * FROM classe_bateau;

Q : Peut-on utiliser PY et TMF ensemble ?
A : Oui ! Chaque bateau peut avoir sa formule.

Q : Comment modifier les handicaps ?
A : Voir HANDICAP_CONFIG.md, section "Modifier les coefficients"

Q : Ça ne marche pas ?
A : Voir Troubleshooting dans GUIDE_UTILISATION_HANDICAP.md
