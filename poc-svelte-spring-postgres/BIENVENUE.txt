🧮 COMMENT ÇA FONCTIONNE ?
═════════════════════════════════════════════════════════════════════════════

1. Vous créez une classe de bateau avec ses handicaps (PY ou TMF)
2. Vous créez un bateau et l'assignez à cette classe
3. Pendant la course, vous entrez le temps brut de chaque bateau
4. Le système calcule AUTOMATIQUEMENT :
   • Le temps corrigé (formule PY ou TMF)
   • La position corrigée (classement équitable)
5. Vous voyez les résultats équitables ! ✨


📊 EXEMPLE DE RÉSULTAT
═════════════════════════════════════════════════════════════════════════════

Avant handicap :
  Position 1 : J70 - 3500 secondes (plus rapide)
  Position 2 : Laser - 3600 secondes (plus lent)

Après handicap (PY) :
  Position 1 : Laser - 435.6 secondes GAGNANT! ✅
  Position 2 : J70 - 358.75 secondes

Pourquoi ? Parce que le Laser a un handicap meilleur que le J70,
ce qui compense son retard et rend la compétition équitable ! ⛵

Je ne sais pas par où commencer ?
  → Lire AIDE_RAPIDE.md (2 min)

Le backend ne démarre pas ?
  → Lire DEMARRAGE_COMPLET.md section "Dépannage"

Le frontend ne compile pas ?
  → Exécuter "npm install" dans le dossier frontend

PostgreSQL ne démarre pas ?
  → Exécuter "docker-compose down -v" puis "docker-compose up -d"

CORS error ?
  → Vérifier que le backend tourne sur le port 8080

Page blanche ?
  → Ouvrir F12 pour voir les erreurs dans la console
