                          🧮 EXEMPLE D'UTILISATION
═══════════════════════════════════════════════════════════════════════════════

SCÉNARIO : Course avec 2 bateaux en handicap PY

Données :
  Laser PY = 1050
  J70 PY = 1000

Vous enregistrez :
  1. Bateau "Laser" → Temps 3600 sec (01:00:00) → Handicap PY
  2. Bateau "J70" → Temps 3500 sec (00:58:20) → Handicap PY

Le système calcule automatiquement :
  Laser : (3600 × 1000) ÷ 1050 = 3428.57 sec = 00:57:08
  J70   : (3500 × 1000) ÷ 1000 = 3500.00 sec = 00:58:20

Affichage dans le tableau :
  Position | Bateau | Temps brut | Handicap | Temps corrigé
  ---------|--------|------------|----------|---------------
     1     | Laser  | 01:00:00   |   PY     | 00:57:08 ⭐
     2     | J70    | 00:58:20   |   PY     | 00:58:20 ⭐

RÉSULTAT : Le Laser gagne même s'il a un temps brut plus long !
           Cela rend la course ÉQUITABLE entre les classes ! ✅

                          📡 API ENDPOINTS DISPONIBLES
═══════════════════════════════════════════════════════════════════════════════

POST /api/race-results/submit
  Enregistrer un résultat brut
  Body : { classeCourseId, bateauId, tempsBrutSecondes, typeHandicap }
  
  Exemple :
  {
    "classeCourseId": 1,
    "bateauId": 1,
    "tempsBrutSecondes": 3600,
    "typeHandicap": "PY"
  }

GET /api/race-results/course/{classeCourseId}
  Récupérer les résultats d'une course (triés par temps corrigé)
  
  Response : [ { id, bateau, tempsBrut, tempsCorrige, position, ... } ]

GET /api/race-results/{id}
  Récupérer un résultat spécifique

DELETE /api/race-results/{id}
  Supprimer un résultat
